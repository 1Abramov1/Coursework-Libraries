Курсовая работа: Приложение для анализа банковских операций

Краткое описание проекта: "Проект по анализу транзакций и расчёту кэшбэка 
с использованием функционального программирования и логирования."


Установка

        1. Убедитесь, что у вас установлен Python 3.6 или более поздняя версия.


		2. Установите необходимые зависимости, выполнив команду:

pip install -r requirements.txt



Использование


		1. Скачайте файл данных и поместите его в папку data в корне проекта.


		2. Запустите основную программу:

python src/main.py


		3. После выполнения программа выведет результаты анализа на экран и сохранит их в указанные файлы логов.

Структура проекта

# src/ - основной код проекта.

# main.py - точка входа в приложение.

# services.py - логика анализа кэшбэка.

# reports.py - генерация отчетов и обработка транзакций.

# logger_config.py - настройка логирования.

# tests/ - тестовые файлы.

# Содержит тесты для всех основных функций проекта.

# logs/ - директория для хранения логов выполнения.

# Тестирование 

Проект покрыт тестами на 82%. Чтобы запустить тесты, выполните команду:


pytest --cov=src --cov-report=html
